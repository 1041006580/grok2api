## 已确认的额度池

### `grok-4` 系列

- `grok-4`
- `grok-4-thinking`
- `grok-4-mini`

观察结果：

- 三者共用一组 Basic 额度。
- 当前观察到的共用额度为 `8`。

### `grok-4.1-fast`

- `grok-4.1-fast`

观察结果：

- 独立于 `grok-4` 系列和 `grok-4.1` 主池。
- 当前观察到的独立额度为 `60`。

### `grok-4.1` 主池

- `grok-4.1-thinking`
- `grok-4.1-expert`
- `grok-4.1-mini`

观察结果：

- 三者共用一组 Basic 额度。
- 当前观察到的共用额度为 `8`。

### `grok-4.1-non-thinking-companion`

- `grok-4.1-non-thinking-companion`

观察结果：

- 观察到单独存在 `10` 的额度。
- 但它与 `grok-4.1` 主池存在联动。
- 实测现象是：当 companion 的 `10` 点额度用完后，`grok-4.1-thinking / expert / mini` 这组 `8` 点额度也会一起不可用。

### `grok-3` 系列

- `grok-3-thinking`

观察结果：

- 三者共用一组 Basic 额度。
- 当前观察到的共用额度为 `60`。

## 使用建议

- 如果要做模型对比测试，不要把同额度池模型混在一起顺序跑，否则后测模型会天然吃亏。
- 如果要做公平对比，优先使用“同一模型单独新 token”或“同一额度池内严格控制顺序”的方式。
- 如果目标是翻译、摘要这类文本任务，`grok-4.1-fast` 与 `grok-3` 系列更适合做独立长测，因为当前观察到的额度更高。
